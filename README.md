# 궤적 비교 — 매핑 vs 주행

사전 매핑 궤적과 실제 주행 궤적을 **카카오 위성지도 위에 겹쳐** 보는 웹 앱.
`map.py`(matplotlib)가 궤적의 *모양*만 비교했다면, 이 앱은 같은 궤적을 **실제 위성 영상
위에** 얹어 "차선 어디를 밟고 갔는지"까지 보여 준다.

CSV 두 개를 끌어다 놓으면 끝이다. 서버도, 로그인도, 데이터 업로드도 없다 —
**파일은 브라우저 안에서만 읽히고 어디로도 전송되지 않는다.**

## 쓰는 법

```bash
npm install
cp .env.example .env        # VITE_KAKAO_JS_KEY 에 카카오 JavaScript 키 입력
npm run dev                 # http://localhost:5173
```

1. 화면 왼쪽 상자에 CSV를 **끌어다 놓거나** `파일 선택`을 누른다. 여러 개를 한 번에 올려도 된다.
2. 파일의 **열 이름을 보고 유형을 자동으로 판별**한다.
   - `latitude`, `longitude` → **매핑** 궤적 (`mapping.py` 산출물, `gps_data/route_*.csv`) — 파랑
   - `fix_lat`, `fix_lon` → **주행** 궤적 (`record.py` 산출물, `ros2bag/*.csv`) — 빨강
   - 둘 다 아니면 `lat`/`lon` 비슷한 열을 한 번 더 찾아보고, 없으면 이유를 적어 거절한다.
3. `지우기`로 궤적 하나만 빼거나, `모두 지우기`로 비우고 다른 버전을 올린다.

### 카카오 키 등록

지도가 회색으로만 뜬다면 십중팔구 도메인 등록이 빠진 것이다.
카카오 developers > 내 애플리케이션 > **플랫폼 > Web > 사이트 도메인**에
`http://localhost:5173`(dev), `http://localhost:4173`(preview)을 넣는다.

## 화면에서 읽는 것

| 항목 | 뜻 |
| --- | --- |
| 위성 / 위성+도로 / 일반 | 카카오 `SKYVIEW` / `SKYVIEW+HYBRID` / `ROADMAP` |
| 단색 / 오차 색 | 오차 색 모드에서는 주행 궤적을 **벗어난 거리에 따라** 초록→빨강으로 칠한다 |
| 최대 n m | 색과 그래프의 눈금. 이 값 이상이면 전부 빨강 |
| 벗어난 거리 | 주행 궤적의 각 점에서 **매핑 궤적(폴리라인)까지의 최단거리** |
| 기준 | 오차를 재는 기준 매핑 궤적. 매핑을 여러 개 올렸을 때 바꿀 수 있다 |
| 오차 그래프 | 가로축은 주행 거리. 마우스를 올리면 그 지점이 지도에 흰 점으로 찍힌다 |

### GPS 정밀도 (RTK 여부)

주행 궤적은 **GPS 정밀도가 높을수록 밝게** 그린다. 오차 그래프 아래의 띠에서도 같은
규칙으로 확인할 수 있고, 띠 위를 끌면 그 지점의 등급과 σ가 읽음줄에 나온다.

| 등급 | 기준 | 밝기 |
| --- | --- | --- |
| RTK 고정급 | σ ≤ 5 cm (또는 `gps_quality` = 4) | 그대로 |
| 중간 | σ ≤ 30 cm | 70% |
| 낮음 | σ > 30 cm | 40% |

이진(RTK냐 아니냐)이 아니라 3단계인 이유가 있다. 실측 주행 하나는 σ가 **1.1 cm ↔ 2.2 m**를
오갔고, 다른 주행 둘은 전 구간 **5~15 cm**였다. 후자를 "RTK 아님" 한 덩어리로 칠하면 정작
볼 것이 사라진다.

판정에 쓸 열은 **있는 것 중 가장 충실한 쪽을 자동으로 고른다**:

1. `gps_sigma_m` — gps.py `_classify()`가 x·y 두 축을 모두 보고 낸 σ. GST 효과가 온전히 반영된다
2. `fix_cov_xx` — √cov. 경도축 하나뿐이지만 GST가 오면 드라이버가 `lon_std_dev`로 대체해 넣는다
3. `gps_quality` — **4(RTK 고정)일 때만** 최상 등급으로 끌어올린다. 다른 값은 드라이버마다 뜻이 달라 σ 판정을 뒤집지 않는다
4. `fix_status` — σ가 아예 없을 때만, 그것도 값이 두 종류 이상일 때만

어느 열로 판정했는지와 **파일에 적힌 상태값 원본**(`gps_quality=2 · fix_status=1` 등)이 통계에
그대로 찍힌다. 판정 근거가 없으면 밝기 구분을 하지 않고 이유를 화면에 적는다.

> `fix_status`가 맨 뒤인 이유: 드라이버가 RTK를 `NavSatStatus.STATUS_GBAS_FIX`(2) 하나로
> 뭉뚱그리는 일이 많다. 실측 파일들이 정확히 그랬다 — 한 파일은 전부 `2`, 다른 파일들은 전부 `1`
> 이라 파일 안에서 구간이 갈리지 않는다.

### 매핑 CSV 없이도 본다

주행 CSV만 올려도 된다. 매핑 기준이 없으면 오차를 잴 수 없으므로 아래 그래프의 세로축이
**벗어난 거리 대신 σ**로 바뀌고, 정밀도 띠와 통계는 그대로 나온다. 세로축이 무엇인지는
그래프 위에 적힌다.

주행 CSV를 여러 개 올리면 지도에는 전부 겹쳐 그려지고, 목록에서 이름을 누르면 그 궤적이
그래프 대상이 된다. 서로 다른 경로를 달린 기록을 함께 올리면 오차가 수십 m로 나올 수 있는데,
눈금을 **자동**으로 두면 그래프가 위쪽에 붙어 뭉개지지 않는다.

### 계산이 맞는지### 계산이 맞는지

주행 기록 CSV에 차량이 스스로 계산해 남긴 `cte_m` 열이 있으면, 이 앱이 계산한 값과
얼마나 차이 나는지를 통계 맨 아래에 같이 보여 준다. 실측 데이터에서는 최대 차이가
**1e-7 m** 수준으로 일치했다 — 즉 화면의 오차 값은 차량 제어기가 보던 값과 같다.

## 계산 방식

위도 1°와 경도 1°는 길이가 다르다(이 위도에서 경도 쪽이 약 0.8배). 위경도 차이를 그대로
거리로 쓰면 동서 방향이 부풀어 오차가 왜곡되므로, `mapping.py`/`driving.py`와 **같은
국소평면 근사**로 미터로 바꾼 뒤 계산한다.

```
x = R·Δlon·cos(lat0)   [동쪽+]        y = R·Δlat   [북쪽+]
```

원점은 **매핑 궤적의 첫 점**이다. 올라온 모든 궤적이 같은 원점을 쓰므로 그대로 겹쳐 볼 수 있다.

몇 가지 데이터 처리:

- 값이 비었거나 `NaN`, `(0,0)` 미수신, 위경도 범위 밖인 행은 버린다.
- 주행 기록 표는 20Hz 스냅샷이라 5Hz GPS 값이 그대로 유지(hold)되어 같은 점이 여러 줄
  반복된다. **연속 중복은 하나로 합친다** — 안 그러면 같은 점이 여러 번 세어져 평균이 왜곡된다.
  (실측: 3,222행 → 806점)
- `board_status` 열처럼 **따옴표 안에 쉼표**가 든 값이 있어 `split(",")`으로는 열이 밀린다.
  따옴표를 지키는 파서를 쓴다.
- 최단거리는 직전에 찾은 구간 주변만 훑되, 창 가장자리에 걸리면 전체를 다시 훑어 정확도를
  지킨다(전수 탐색과 결과가 완전히 일치하는 것을 확인했다).

## 구성

```
index.html
src/
  App.tsx                    화면 전체 — 파일 받기·지우기·상태
  main.tsx
  index.css
  kakao.d.ts                 카카오 SDK 타입 (쓰는 것만)
  hooks/useKakaoLoader.ts    SDK 동적 로드 (autoload=false → kakao.maps.load)
  lib/csv.ts                 CSV 파싱 + 유형 자동 판별
  lib/geo.ts                 국소평면 변환 · 최단거리 · 통계 · 오차 색
  components/
    MapView.tsx              카카오 지도, 폴리라인, 위성 전환
    TrackList.tsx            올라온 궤적 목록
    ErrorProfile.tsx         오차 그래프
    StatsPanel.tsx           통계표
```

## 배포

`npm run build` → `dist/`. GitHub Pages 워크플로가 `.github/workflows/deploy-pages.yml`에
있고, `BASE_PATH`와 `VITE_KAKAO_JS_KEY`(리포지토리 시크릿)를 주입한다. 배포한 도메인도
카카오 콘솔의 플랫폼 > Web 에 등록해야 한다.
